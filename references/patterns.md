# AI 味模式目录（含真实修订案例）

每条模式：**特征 → 为什么 AI → 修订动作 → 案例（原文 → 改后）**。案例来自一次真实的多轮修订（24 页选型汇报 PPT），可直接对照。

快速自检：句子里出现「我们怎么筛 / 怎么标 / 怎么核」「靠的是…」「是收口动作」「不隐藏」「皆可查」「逐项标注」→ 基本是过程旁白，删。

---

## 1. 过程宣言 / 工作流程旁白

**特征**：句子在叙述作者自己的调研、筛选、标注动作，而不是陈述对象内容。
**为什么 AI**：人做汇报讲"结论与依据"，AI 爱讲"我做了什么流程"；这是把自己的工作日志投影给观众。

**案例**：
- 封面「把 35 个型号筛成 7 个，靠的是三条硬标准」→ **删除**（候选规模一行已足够；筛选过程放讲稿）
- 指标行「数据状态逐项标注：已核实官网 / 厂商宣称 / 政采实锤」→ **删除整行**（这是标注规则说明，不是需求指标）
- 横幅「口径函 + 样机实测是收口动作——把「演算与宣称」升级为「实测与结论」」→ **删除横幅**（左右两卡已说完计划）
- 结尾口号「每个数字都有出处——这就是我们筛出 7 强的方式」→ **删除**；卡片改为客观规模数字（候选 22 家 / 35 型号 / 案例 39 条 35 条核至原文）

## 2. 金句副标题 / 格言槽

**特征**：章节页大标题下固定位置放一句打磨过的对仗句；多页同构出现 = 模板指纹。
**为什么 AI**：句子不提供本章内容，只提供"有观点的感觉"；人写章节页要么空着、要么写内容导览。

**案例**：
- 「需求不是口号，要翻译成可验收的指标」→「探测目标 · 探测距离 · 平台约束」（本章内容导览）
- 「推荐要能被追问，部署要能落地」→「推荐结论 · 光电联动部署 · 风险与下一步」
- 「侦测流水线、识别三路线、RID 报文——每层都能拆开讲」→「侦测流水线 · 识别三路线 · RID 与 DroneID · 链路演算」

**修订**：删除，或改写为"本章包含什么"的中性导览。

## 3. 防御性标注（口径徽章 / 页脚三重来源）

**特征**：同一口径信息以徽章、列头、页脚、警示条反复出现；免责式措辞（"未经核实""不隐藏"）。
**为什么 AI**：防御性写作——怕被质疑而把免责做成视觉系统；人只在一处说一次。

**案例**：
- 表格连续 7 个「待口径函」→ 统一「待确认」
- 页脚「S5 行41/42 · S1 行5 · 参数=厂商宣称 · 价格=三项目实锤」→ **删除**（页面内已有一句资料来源）
- 徽章「情景数据 · 工程假设值」→ 页脚一行正常假设说明「EIRP 为法规上限，G_rx / S 为工程假设」
- 警示条「本页参数未经官网核实——不隐藏」→ 改为一句结论「参数结论待厂商确认后更新总表」

**修订**：一页说一次，写成普通句子或"注："；徽章只留给真正需要强调的单一结论。

## 4. 自评与纪律宣言

**特征**：向观众声明自己的工作纪律、严谨程度。
**案例**：「以上均已列入口径函与核验清单，**不隐藏**」「每一层的排除原因**逐条可回查**」「**全部数据可回溯**（会留档备查）」→ 删除；确需保留的改为客观事实句（"原始公告与链接可提供"）。

## 5. 修辞尾缀

**特征**：事实陈述后用破折号接一个金句。
**案例**：
- 「带宽换灵敏度 · 位宽换动态范围 · 孔径换精度**——每级都有代价，没有免费指标**」→ 删尾缀
- 「未知机型 → AI 兜底**——三路线互补，缺一不可**」→ 删尾缀（"互补"前文已说）

**修订**：事实陈述独立成句；金句若确有力，降级到讲稿说出口。

## 6. 说话腔标题注释

**特征**：标题旁小字放"点评"而非内容。
**案例**：「每一级都有代价」「两种最容易混淆的「ID」」「数字可信，但有边界」→ **删除**（观众从标题和正文已能得到）。

## 7. 备注里的 AI 味

**特征**：自我喊话、内部文档点名、把标注规则读出来。
**案例**：
- 「千万不要在答辩时把它说成已入选设备」→ **删除**（自我喊话）
- 「技术口径：《技术细节速成手册》§2-3」→ 「技术口径：公开国家标准与厂商公开资料 · 内部整理」（内部手册名不外显）
- 「页面上已经标注情景数据」→ **删除**（把页面标注规则读出来）

**修订**：保留"高概率追问 + 一句话应答"的备答结构；删喊话与元话语。

## 8. 视觉海报化

**特征**：深色渐变底 + 发光标题 + 纯装饰几何（频谱线、扫线、光斑）→ 宣传海报感、审美疲劳。
**修订**：换白底学术风——白底、直角/近直角卡片、单细线规则、去渐变去发光、删除无信息职责的装饰元素；主色只作标点式强调。
**工程提示**（ppt-master 项目）：不要局部改色——更新 `spec_lock.md` 的 `visual_style` 与 `colors.*`、`design_spec.md` §III，然后全册重绘；preset 片段（trapezoid/chevron 等）改漆后必须重跑 `preset_shape_svg.py` 重新生成；原生 Chart/Table 改配色后重跑 `stamp_native_fallbacks.py`。

---

## 保留项（不要过度删除）

- 数字上的事实性限定词「宣称 / 演算 / 实锤」——它改变读数方式，是内容不是防御
- 每页至多一句"资料来源：…"（学术惯例）
- 用户明确绑定或要求保留的句子——拿不准先问
